Top Downloader App Codes for the Best IPTV Players in the UK

What Is a Downloader Code, Exactly?

Downloader is a free app in the Amazon Appstore, made by AFTVnews, and it is the standard way to install apps not listed in the Amazon Appstore on a Firestick. Many of the best IPTV players fall into that group. Instead of typing a full download address with a remote, you open Downloader, type a short numeric code, and it fetches the app file for you.

That shortcut is also the weakness. A code only works while the address behind it still works. If a developer moves their file or their site goes offline, the code breaks, and every guide that printed it becomes out of date at once. So a list of codes is only useful if it also tells you which ones are still live. Before you use any code below, it helps to understand what IPTV is and how to set up IPTV once the player is installed. Our Firestick for IPTV page covers the rest.

How Downloader Codes Work

A Downloader code is not a password and it does not unlock anything. It is a short alias for a download link, created so a long address can be typed with a television remote. Enter the code, press Go, and Downloader downloads the app file and asks if you want to install it. The whole process takes a minute on a decent connection.

Codes are created by the people who host the file, not by Amazon, and they can be changed or removed without notice. That is why the same player can have different codes in different guides: several sites create their own shortcuts to the same file, and older shortcuts die when the file moves. Always check the date on a code list.

Downloader itself is safe and legitimate, and sideloading through it is a supported Fire OS feature. The risk is the file you fetch: only install a player from the developer's own address or a code that points to it, and never pay for a code.

Before You Start: Check Your Firestick Can Sideload

Not every Firestick can install apps this way. The newest Firestick models run Amazon's Vega OS, which blocks sideloading and the Downloader app completely. On those models, none of the codes in this guide will work, so check your model first: Fire OS is fine, Vega OS needs a different device or a player from the Amazon Appstore.

On a Fire OS stick, install Downloader from the Amazon Appstore, then open Settings, go to My Fire TV, then About, and press the device name seven times to unlock Developer Options. Go back, open Developer Options, and turn on Install Unknown Apps for Downloader. Without that permission, Downloader can download a file but Fire OS will refuse to install it. How to Install a Player with a Downloader Code

The steps are the same for every player. Only the code changes.

  1. Install Downloader. Search for Downloader in the Amazon Appstore, install it and allow it to access storage when asked.
  2. Allow unknown apps. In Settings, under Developer Options, turn on Install Unknown Apps for Downloader, as described above.
  3. Enter the code. On Downloader's home tab, highlight the address box, type the code for your player, and press Go.
  4. Install the app. When the download finishes, press Install, then Done. Delete the downloaded file when asked, to save space.
  5. Log in with your IPTV details. Open the player, choose the Xtream Codes login, and enter the server address, username and password from your subscription.

That login is the same on every player: the player only shows your channels, and your subscription provides them. If the guide looks empty after logging in, read our EPG guide and the fix for an EPG that is not updating. If channels will not load at all, see channels not loading.

The Codes, Player by Player

TiviMate — Code 272483

TiviMate is the player most experienced viewers choose first, and its code is the most reliable in this guide. The code 272483 is the official Downloader shortcut for TiviMate, and every recent guide we checked gives the same number. It was still working in late 2026. If you only install one player, install this one.

TiviMate earns its reputation with a fast programme guide, catch-up television and recording. The free version covers live television; the full features need a Premium licence, bought through the TiviMate Companion app on an Android phone. Our TiviMate guide covers the setup in full.

IPTV Smarters Pro — Old Code 6468112 Is Dead

IPTV Smarters Pro is the player with the messiest codes. Several guides still print different numbers for it, including 6234188, 444752, 80911, 78001 and 808328, and they cannot all be right. The code most guides used to print, 6468112, no longer works: the developer's main site has been offline since August 2026, and the code pointed to it.

That does not mean the player is gone. The current build, version 5, is still hosted on the developer's second download address: use that full address in Downloader instead of guessing another number. Our IPTV Smarters Pro guide covers the setup.

XCIPTV Player — Codes Disagree

XCIPTV is a clean, simple player that suits viewers who want fewer menus and a straightforward channel list. Its Downloader code is the least certain in this guide: some recent guides give 285888 and others give 47295. We could not confirm either as the official code.

If you want XCIPTV, try 285888 first, then 47295 if Downloader cannot find the file. If neither works, use the player's official website address in Downloader instead, and never download it from a site you do not recognise. Our XCIPTV guide covers the player in full.

IBO Player and Smart IPTV — No Downloader Code Needed

Not every good player needs a code. IBO Player works differently: you install the app, then activate it with your device's MAC address on the developer's website. There is no Downloader code to type, and any site offering one is offering something unofficial. The same applies to Smart IPTV, which is installed from an app store and activated online. Our guides to IBO Player and Smart IPTV walk through activation.

When a Code Does Not Work

A failed code is common, and it is rarely your fault. First, check the number: a single wrong digit sends Downloader to the wrong address. Second, check your connection: Downloader needs the internet to look the code up, so test another app first. Third, check the date on the guide you copied the code from: if it is a year old, the code may have died since.

If the code still fails, stop trying numbers and use the full official address instead. If that fails too, pick a player whose code is confirmed, such as TiviMate, rather than hunting for a copy on an unfamiliar site: a file from an unknown source can be an old version or a modified copy.

Two other errors are common after a download. If Fire OS says the app cannot be installed, Install Unknown Apps is still off for Downloader, so switch it on. If the app installs but will not open, clear its cache and restart the Firestick. For playback faults, our guides to IPTV buffering and IPTV freezing cover the fixes.

Which Player Should You Pick?

Pick TiviMate if you want the best player and the simplest install: its code works, its guide is the fastest, and its features cover everything from catch-up to recording. Pick IPTV Smarters Pro if you already know it from another device, but install it from the developer's current address, not from an old code. Pick XCIPTV if you want the simplest screen and the fewest settings, and accept that its code may need a second try. Pick IBO Player or Smart IPTV if you watch on a smart television as well as a Firestick.

Whichever player you choose, keep only one or two installed. Five players do not give you five times the channels: they give you five apps competing for the same small storage, and a Firestick with 16 GB fills fast. Uninstall the players you do not use. Frequently Asked Questions

Are Downloader codes free?

Yes. A code is a free shortcut to a free download. Never pay anyone for one.

Is it safe to sideload an IPTV player with Downloader?

Downloader is a legitimate app from the Amazon Appstore, and sideloading is a supported Fire OS feature. The safety comes from the source: only install a player from the developer's own address or a code that points to it.

Why did a code that worked last year stop working?

Because the address behind it changed. A developer may move their file or close a site, and the code dies with it — as with the old IPTV Smarters Pro code in 2026.

Can I use the same IPTV subscription in any of these players?

Yes. Your IPTV UK login works in the same way in each player, through Xtream Codes or a playlist. Check your plan on the IPTV UK pricing page to watch on two screens at once.

Do I need a different code for each Firestick in the house?

No. A code is the same on every Firestick: install the same player on each stick, then log in with your subscription on each one.
